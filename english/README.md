# English Master (Grammar Gym)

Клиентско уеб приложение за упражняване на английски, насочено към българи. Работи изцяло в браузъра, без бекенд: React + Vite + TypeScript + Tailwind, `localStorage` за настройки и напредък, Web Speech API за произношение.

## Инсталация и стартиране

```bash
npm install
npm run dev        # http://localhost:5173
```

## Билд

```bash
npm run build      # dist/index.html, всичко (JS + CSS) е инлайнато в един файл
npm run preview    # локален преглед на билда
```

Билдът използва относителни пътища (`base: './'`) и се събира в един HTML файл (`dist/index.html`), затова може да се качи на GitHub Pages или произволен статичен хостинг. Единственият външен ресурс е Google Fonts.

## Проверка на генераторите

```bash
npm test           # vitest: 5000+ случайни изречения за членуване и времена, плюс останалите генератори
```

## Структура

```
src/
  data/         думи, шаблони и тагове (лесни за разширяване)
  data/lexicon/ общият речник (1500+ думи по категории), от който черпят модулите Думи, Членуване и Части на речта
  generators/   код, който сглобява изречения от данните и изчислява верния отговор
  modules/      осемте модула (по един React компонент)
  components/   общи UI компоненти (статистика, бутон за произношение, изречение, бар за действие)
  lib/          speak (един споделен глас), storage, matching (гъвкаво сравнение), progress (приоритет на грешните)
  hooks/        useStored (localStorage), useSession (брояч), useKeys (клавиши)
tests/          проверки на генераторите
```

## Модули

1. Неправилни глаголи (V2 / V3, типове AAA / ABB / ABC / ABA, основни 60 или всички)
2. Членуване (a / an / the / -), 16 правила с включване и изключване, многоместни изречения
3. Времена (8 времена, отрицания, съкратени форми, going to)
4. Фразови глаголи (бутони или писане)
5. Неброими съществителни (much / many, is / are, a / some / a piece of, намери грешката)
6. Думи (флашкарти, EN → BG / BG → EN, категории)
7. Фонетика и IPA (справочник с произношение на всяка примерна дума)
8. Части на речта (маркиране на думи в изречение)
9. Списък глаголи (всички неправилни глаголи в таблица с търсене при писане)

## Как да добавиш съдържание

- Нова дума за речника: ред в съответния файл в `src/data/lexicon/` (`['en', 'бг', pos, категория, 'тагове']`). Таговете (person, object, food, animal, place, unc...) определят дали и как думата се използва от генераторите за членуване и части на речта.
- Нов неправилен глагол: ред в `src/data/irregularVerbs.ts`.
- Специална дума за членуване (с плуral или семантика, която речникът не дава): обект в `NOUNS` в `src/data/articles.ts`; ако буквата и звукът не съвпадат (hour, university), добави я в `src/data/sound.ts`.
- Ново сказуемо за времената: ред в `PREDICATES` в `src/data/tenses.ts` (`{poss}` става my / his / her...).
- Нов фразов глагол, неброимо, дума или фонема: съответният файл в `src/data/`.
