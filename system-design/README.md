# Билд на приложението

Документите в папка `md/` са източникът на истината. Този билд ги събира в една HTML страница
с меню, по една страница на документ, и рендерира Mermaid диаграмите в браузъра.

```bash
cd system-design
npm install
npm run build        # създава dist/index.html
```

Редът на страниците и кратките имена в менюто са в `manifest.json`.
